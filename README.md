# cut-coach 意見回饋

這裡收集 cut-coach 測試版使用者的問題回報與功能建議。

## 怎麼回報
1. 點上方的 **Issues** → **New issue**。
2. 選一個範本：
   - **問題回報**：功能壞了、結果怪怪的、App 當掉。
   - **建議**：希望增加或改變的功能。
   - **AI 結果不準**：照片或文字的熱量、蛋白質、訓練建議明顯不對。
3. 照範本填寫後送出。

## 請注意：這裡是公開的
任何人都看得到這裡的內容。請**不要**貼上：
- 你的體重、體脂、用藥、身體狀況等健康資料
- 含有臉、住址、車牌、收據姓名的照片
- 邀請碼或任何帳號資訊
- App「回報問題」匯出的 JSON 檔（裡面有你的紀錄）

需要附上這些資料才能說清楚的問題，請在 issue 寫「有私人資料要補充」，我們會私下聯絡你。
